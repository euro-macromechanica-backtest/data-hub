# 📂 Сырые и подготовленные минутные данные EUR/USD, отчёты по разрывам. Источник [HistData](https://www.histdata.com)

**Минутные данные EUR/USD (с января 2001 по 31 августа 2025)**

## 📌 Источник и формат

История котировок получена с сервиса **[HistData](https://www.histdata.com)** в формате **Generic ASCII M1**:  
<http://www.histdata.com/download-free-forex-historical-data/?/ascii/1-minute-bar-quotes/EURUSD>

Область охвата: только EURUSD M1 (без других инструментов).

---

**Сырые M1-данные** — формат времени: фиксированный EST (UTC−05:00, без DST). См. FAQ: <http://www.histdata.com/f-a-q/>  
Пути: `raw/...csv`

**Отчёты по разрывам** — текстовые файлы-приложения к сырым годовым M1.  
Пути: `raw/...txt`

**Подготовленные M1-данные** — готовые к бэктесту минутные ряды (UTC+00:00), без искусственного заполнения пропусков; разделитель — `;`.  
Пути: `/prepared/...csv` 
*(Подготовка минутных данных была выполнена с помощью [minute data normalizer](https://github.com/euro-macromechanica-backtest/data-preparation-toolkit/tree/main/minute_data_normalizer) в репозитории data-preparation-toolkit)*

**Референсные тиковые данные HistData** — для сопоставления качества.  
Пути: `tick_data_reference/...`

---

## 📜 Прозрачность

Для обеспечения прозрачности и доказательства подлинности исходных данных зафиксированы следующие артефакты:

1. **Единый манифест SHA-256 `eurusd_raw_2001-2025-08.sha256`** — содержит все сырые годовые минутные данные, полученные с HistData, и снабжён **SHA-256-хэшем**, **GPG-подписью** и **OTS-якорем** (OpenTimestamps) в блокчейне.
2. **Единый манифест SHA-256 `eurusd_prepared_2001-2025-08.sha256`** — содержит все подготовленные годовые минутные данные; также имеет **SHA-256-хэш**, **GPG-подпись** и **OTS-якорь**.
3. **Единый манифест SHA-256 `status_reports_2001-2025-08.sha256`** — содержит все отчёты по разрывам годовых минутных данных, полученные с HistData; также имеет **SHA-256-хэш**, **GPG-подпись** и **OTS-якорь**.
4. **SHA-256, GPG-подпись и OTS-якорь** случайной выборки месячных тиковых данных, полученных с HistData, — как референс качества для бэктеста на тиках.

## 🔍 Назначение

- **SHA-256-хэш** — проверка целостности файла.  
- **GPG-подпись** — подтверждение авторства и подлинности.  
- **OTS-якорь** — блокчейн-доказательство существования данных на определённый момент времени.

## ⚠️ Важно

- Данные были выгружены с **[HistData](https://www.histdata.com)** в тот момент, когда они были доступны в исходном виде.
- **HistData** может обновлять архивы (в том числе удалять разрывы).
- Хэши, подписи и OTS доказывают, что бэктест проводился **именно на этих данных**, а не на изменённых позднее.
- **Лицензия / Условия:** применяются исходные условия провайдера; повторное лицензирование в этом репозитории не допускается.
