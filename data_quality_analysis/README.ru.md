# 📈 Анализ отчётов разрывов M1-данных EUR/USD

> 📅 **Охват:** 2001-01-01 → 2025-08-31 (24 года 8 месяцев)  
> 🕒 **Часовой пояс исходных минутных данных:** **UTC−05:00 (fixed, без DST)**  
> 🌐 **Источник минутных данных:** HistData.com  
> 🎯 **Назначение:** backtesting (бэктест торговой стратегии **EMM**)

---

## 🧭 Обзор

Проанализированые **годовые отчёты по разрывам (gap/status reports)**, полученные с HistData на базе минутных данных EUR/USD за период **1 января 2001** — **31 августа 2025**.  
Исходные минутные котировки находятся во **фиксированном UTC−05:00 (без DST)**; подготовленные результаты анализа разбиты по годам (для **2025** — январь–август).  
📥 **Входные данные:** годовые текстовые отчёты по разрывам, полученные с HistData (`source_data/raw/...txt`).

---

## 📊 Артефакты анализа

- Сводный отчёт по количеству разрывов по 5-минутным «корзинам» длительностей —  
  `DAT_ASCII_EURUSD_M1_YYYY.txt_gap_bucket_counts.csv`
- Отчёт по датам —  
  `DAT_ASCII_EURUSD_M1_YYYY.txt_gap_buckets_by_date.csv`
- SVG-визуализация разрывов —  
  `DAT_ASCII_EURUSD_M1_YYYY.txt_gaps_scatter.svg`
- **Манифест**, включающий SHA-256 всех входных и выходных файлов.

**Аналитическая база:** расчёт на сетке **M5** (разрывы ≥ 5 минут), так как стратегия оперирует таймфреймами **M5**.

## 🔍 Прозрачность и воспроизводимость

Анализ отчётов выполнен с помощью **[minute data analyzer](https://github.com/euro-macromechanica-backtest/data-preparation-toolkit/minute_data_analyzer)** в **data-preparation-toolkit**.  
**Единый манифест SHA-256 годовых манифестов** расположен в `/integrity/data_quality_analysis` и снабжён **GPG-подписью** и **OTS-якорем (OpenTimestamps)**.
